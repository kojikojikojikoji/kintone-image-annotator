# kintone-image-annotator

English version: [README.md](./README.md)

kintoneの添付ファイルフィールドにある画像へ矢印・図形・テキストを描き込み、注釈入りのコピーを同じフィールドに保存する。元のファイルはそのまま残るため、描き込み前の状態にはいつでも戻れる。

プラグインが動くのはレコード詳細画面。読み書きはすべて、サインイン中ユーザーのセッションでのkintone REST API経由で行う。外部サーバーには何も送らず、kintoneの外にデータを保存しない。

## 機能

- 設定した各添付ファイルフィールドの直後に「注釈を追加」ボタンを追加する。表示されるのは、現在のユーザーがレコードを編集できるときのみ。
- 添付ファイルの選択画面を開く。注釈を付けられるのはJPEG・PNG・WebP・GIFで、それ以外の形式はグレーアウト表示になる。
- エディタには6種類のツール（ペン・直線・矢印・矩形・楕円・テキスト）、6色のプリセットカラー、3段階の線幅、取り消し・やり直し（50ステップ）、全消去、ズームとパン（50〜400%）がある。
- 保存時には画像と図形をラスタライズし、`<name>_annotated_<timestamp>.<ext>` という名前の新規ファイルとしてアップロードして、同じ添付ファイルフィールドに追加する。JPEG元画像はJPEG（品質0.9）のまま、PNG・WebP・GIFは透過を保ってPNGで書き出す。
- 図形のベクターデータをテキストフィールドに保存しておけば、注釈済みの画像を後から開き直して編集し直せる（任意設定）。

## 対応画面

- レコード詳細: 対応。
- レコード一覧・作成・編集: 非対応（これらの画面では添付ファイルに確定したファイルキーがまだない）。
- モバイル: 非対応。タッチ入力はiPadのデスクトップ表示で受けられる。

## インストール

1. プラグインのバンドルをビルドする。
   ```
   npm install
   npm run build
   npm run pack
   ```
   `npm run pack` が `dist/plugin.zip` を出力する。初回実行時には署名鍵の `private.ppk` も作成される。`private.ppk` は保管し、以降のビルドでも使い回すこと。プラグインIDが変わらずに済む。git管理外になっている。
2. kintoneのシステム管理またはアプリのプラグイン設定を開き、`dist/plugin.zip` をアップロードする。
3. 対象のアプリにプラグインを追加する。

## 設定

アプリのプラグイン設定を開く。

- 対象の添付ファイルフィールド（必須）: 1つ以上の添付ファイルフィールドにチェックを付ける。選んだ各フィールドの後ろにボタンが出る。
- 注釈データフィールド（任意）: 文字列（複数行）フィールドを選ぶか、「保存しない」のままにする。設定すると図形データをそのフィールドに書き込み、注釈済みの画像を再編集できるようになる。このフィールドはプラグインが専用に使うので、手で編集しないこと。

フィールドの参照はフィールドコードで保持するため、フィールドのラベルを変えても設定は壊れない。

## 動作の詳細

- ファイル名: 注釈済みファイルは `<元のファイル名>_annotated_<YYYYMMDD-HHmmss>`。拡張子は、JPEG元画像ならJPEGのまま、それ以外は `png`。
- 再編集: データフィールドを設定している場合、図形データを持つ画像には「再編集」バッジが付く。選ぶと元の画像を読み込み、図形を編集可能なオブジェクトとして復元する。元の画像が既にないときは、注釈済みの画像を開いて直接描き込む形になる。
- 添付ファイルの保全: kintoneは更新時に添付ファイルフィールドを丸ごと置き換える。保存フローではレコードを再取得し、既存のすべてのファイルキーを保持したうえで新しいファイルを追加するため、既存の添付ファイルは失われない。更新にはレコードのリビジョンによる楽観ロックを使い、競合する変更があった場合は保存を止めて再読み込みを促す。
- 保存先: 図形データは設定したレコードのフィールドに入る。localStorageは使わない。編集途中の内容は、エディタを閉じた時点で破棄される。

## 制限事項

- 描いた図形を個別に選択・移動・リサイズ・削除することはできない。修正手段は取り消しと全消去のみ。確定したテキストの再編集もできないので、取り消して打ち直す。
- 矩形と楕円の塗りつぶし、フォント選択、太字・斜体、スタンプ、モザイク、回転、切り抜きはない。
- テキストは端末の `sans-serif` フォントで描画されるため、正確な字形は保存した端末に依存する。
- 長辺8000px超の画像は編集用に8000pxへ縮小され、保存されるファイルもその縮小サイズになる。
- アニメーションGIFは最初のフレームだけに注釈を付け、PNGで保存する。PDF・HEIC・TIFFには注釈を付けられない。
- モバイル画面は非対応。

## 開発

```
npm install       # install dependencies
npm run typecheck  # tsc --noEmit
npm test           # vitest (unit tests for core/)
npm run build      # build dist/desktop.js and dist/config.js
npm run lint       # eslint
npm run pack       # build then create dist/plugin.zip (and private.ppk)
```

E2E仕様は `test/e2e` にあり、開発用のkintone環境に対して実行する。`KINTONE_BASE_URL`、`KINTONE_USERNAME`、`KINTONE_PASSWORD`、`KINTONE_APP_ID` を環境変数から読み、未設定ならスキップする。CIには含めていない。
